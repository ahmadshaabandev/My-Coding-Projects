Hello! I'm Mommy.

A grown-up sets up the app once, for the whole family.

Good to know

Mommy is a computer program (an AI). It is not a person, and it is not your mum or dad. It can make mistakes, so a grown-up should stay close.

For the grown-up

Family setup

Your family’s list (children, tasks, stars, rewards and the PIN) is saved only in this browser, on this device. To check a text or read it out, the Mommy server gets the text and its language, and for a recitation or dictation check also the child’s age group; a Quran check sends the surah and ayat numbers instead. The server does not keep the texts or the age group; its log notes the language, the kind of check and the ayat numbers.

For the parent

Mommy handles the recordings and photos in memory and never saves them.

Parent PIN

The PIN is a child lock: it keeps the parent area for the grown-ups. It has 4 to 6 digits.
