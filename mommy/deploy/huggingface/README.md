This Space is a private test of Mommy, a prototype tutor that helps children practise
reciting and writing school texts in Arabic, English and French. It is protected by an
access code: only the people the owner sent the link to can use it. Audio and photos
sent to it are processed in memory and are not stored. The source code and its
documentation are in the project's repository.
