About the converter

What it does, and what it does not.

What it does

  • Prints your HTML and CSS with Cloudflare Browser Run, which runs headless Chrome on Cloudflare’s network, on A4, US Letter or A5, portrait or landscape, with [[pdf.defaultMarginMm]] mm margins.
  • Downloads images from public https:// addresses before printing and embeds them, up to [[pdf.maxRemoteAssets]] of them and [[pdf.maxAssetMb]] MB together. data: images work too.
  • Embeds the fonts Inter, Source Serif 4 and JetBrains Mono when your CSS names them. Other fonts come from Cloudflare’s browser.
  • Sends the finished file straight back to your browser as a download. Your HTML and the PDF are not kept.

What it does not do

  • It does not open a web page by its address. Paste the HTML itself.
  • It does not run JavaScript. Scripts and on... attributes are removed before printing, so content that a script would add does not appear.
  • It does not load stylesheets or fonts from other sites: <link> elements are removed, and @import or a remote @font-face is refused. Put the CSS in the CSS box.
  • It always prints the “[[pdf.freeMark]]” line in the footer. For documents without it, use the API on a paid plan.

Templates, not just pages

Through the API, the same HTML becomes a template: write {{customer}} where a value goes and send the values as data, and repeat table rows with {{#items}} ... {{/items}}. The values are always text, so nothing a customer types can turn into markup.

The API adds headers and footers with page numbers, margins of your choice and stored PDFs with a public URL. Your own HTML and CSS

Do this via the API

Send the same HTML and CSS to POST /v1/pdf with an API key from your dashboard, and ask for the PDF itself with "response": "binary".

curl [[site.url]]/v1/pdf \
  -H "Authorization: Bearer ltc_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "html": "<h1>Hello, {{name}}</h1><p>Your order has shipped.</p>",
    "css": "h1 { font-family: \"Source Serif 4\", serif; }",
    "data": { "name": "Amara" },
    "pdf": { "format": "letter" },
    "response": "binary"
  }' \
  -o order.pdf

FAQ

Questions about HTML to PDF.

Short answers about what prints and what does not.

Can I convert a web page by pasting its URL?

No. The converter only prints HTML that you paste, and the browser that prints it has no network access. Open the page, save or copy its HTML and CSS, and paste them here. Remember that a page you did not write may belong to someone else.

Why does my chart or my script not show up?

JavaScript is turned off and scripts are removed before printing. Anything a script would draw or load is missing. Render charts as images or SVG first, or put the finished HTML in the box.

How do I start a new page, or keep a table row together?

With CSS, as Chrome prints it: break-before: page on an element starts a new page with it, and break-inside: avoid keeps an element, such as a table row, on one page. A table’s <thead> repeats at the top of each page.

Which fonts can I use?

Inter, Source Serif 4 and JetBrains Mono are embedded when your CSS names them, for example font-family: 'Inter', sans-serif;. Other names fall back to the fonts installed in Cloudflare’s browser, which cover many scripts, including Chinese, Japanese, Korean and Arabic. Fonts from Google Fonts or another site cannot be loaded.

How large can the document be?

Up to [[pdf.maxHtmlMb]] MB of HTML, [[pdf.maxCssKb]] KB of CSS and [[pdf.maxPages]] pages. A longer document is refused, so split it. Printing gets [[pdf.renderTimeoutSeconds]] seconds.

Do you keep my HTML?

No. Your HTML and CSS reach our server once, only to be printed, and the PDF goes straight back to you without being stored. We count PDFs per network for the current hour, and log the pages and the printing time of each PDF, not its content. Privacy policy

Is it free?

Yes, without an account: up to [[pdf.toolPdfsPerHour]] PDFs per hour from one network, and after a few you may be asked to confirm you are a person. Every page carries the “[[pdf.freeMark]]” line. For more, or PDFs without the line, use the API.
