How it works

A real QR code on a plain plate, over a drawn picture.

Why it scans

  • The QR code is made by an ordinary QR library, with error correction level [[ai.qrErrorCorrection]], not drawn by the AI model.
  • It sits on a solid light plate with a quiet border of [[ai.qrQuietZoneModules]] modules. Its dark squares have a contrast of at least [[ai.qrMinContrast]]:1 against the plate, and the code takes at least [[ai.qrMinWidthPercent]]% of the image width.
  • The AI model draws only the picture around the plate. Your link is not sent to it.
  • Before you see the code, our server draws the image and reads it back with a QR decoder, at full size and at one third of the size. The decoded text must be exactly your link. If it is not, the code is made larger, then plain black on white. A code that still does not read back is never shown or charged.
  • No check covers every phone camera, printer and screen. Scan the code with the phones you have before you print many copies.

What you get

  • Free preview: [[ai.qrPreviewPx]] × [[ai.qrPreviewPx]] PNG with a small corner mark. No account.
  • Full size: [[ai.qrFullPx]] × [[ai.qrFullPx]] PNG, plus the QR code alone as an SVG file, for [[ai.creditsPerImageText]].
  • The code is static: it holds your address itself and does not pass through a redirect of ours, so it cannot be changed later and does not stop working if you leave.
  • Links to domains that Cloudflare’s security DNS resolver lists as malware or phishing are refused, as are links on our own blocklist.

FAQ

Questions about AI QR codes.

Including what it does not do.

Is the QR code part of the picture?

No. The code sits on a solid light plate over the picture, with a plain border around it. A code blended into a picture can be hard for some phones to read; this one keeps the code plain so that it scans.

Will every phone read it?

Every code is decoded on our server before you see it, at full size and at one third of the size, and only a code that reads back as exactly your link is shown. That catches codes our decoder cannot read, but no check covers every phone camera, printer, screen and light. Test it with your own phones first, especially before printing.

Can I change the link later?

No. The codes are static: the address itself is in the code, with no redirect service of ours in between. To change the link, make a new code.

Does the AI see my link?

No. The image prompt is written by our server from the style and the colours you choose, in our own words. Your link is never part of it: the QR code is made from the link by our server, after the picture is drawn.

Which links are refused?

Anything that is not an http or https address, an address longer than [[ai.maxUrlChars]] characters, one with a user name or password in it, one whose host is an IP address, a known link shortener, a domain that Cloudflare’s security DNS resolver lists as malware or phishing, and anything on our own blocklist. A refused link is recorded so that we can look into abuse.

What is the free preview?

A [[ai.qrPreviewPx]] × [[ai.qrPreviewPx]] PNG with a small corner mark, made after a quick check that you are a person. From one network you can make [[ai.freePreviewsPerPageText]] per link a day, and at most [[ai.freePreviewsPerDay]] free previews a day in all. It is kept for [[ai.previewHours]] hours.

What is kept, and for how long?

A preview and the picture behind it are kept for [[ai.previewHours]] hours and then deleted. A full-size code and its SVG are kept until you delete them or your account is deleted. The link you entered is kept with the code. A refused link and a report are kept for [[ai.abuseRetentionDays]] days.
